
# Equity Research — DCF Valuation Models
Independent fundamental analysis built from SEC 10-K filings, earnings transcripts, and public market data.

Company covered - Broadcom
Ticker- AVGO
Sector- Semiconductor 
Implied Price - $133
Market Price - $462
View - Overvalued 

Methodology

5 year unlevered FCF projection anchored in SEC 10-K actuals
WACC via CAPM using Damodaran equity risk premium
Terminal value via Gordon Growth Model and EV/EBITDA exit multiple
Sensitivity analysis across WACC and growth rate scenarios

Tools Used: Microsoft Excel, SEC EDGAR, Earnings Call Transcripts
